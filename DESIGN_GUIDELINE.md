# Дизайн-гайдлайн газети «Вісник Чату»

Цей документ визначає єдині візуальні та технічні стандарти верстки жартівливої газети.  
**Еталон (золотий стандарт) — щоденний випуск.**  
Усі елементи (включно з тижневими спецвипусками, іграми та майбутніми модулями) зобовʼязані суворо дотримуватися цих правил, щоб уникнути хаосу («messy»), випадкових розмірів шрифтів та несумісних стилів.

---

## 1. Філософія дизайну та ключові принципи

1. **Сучасна іронічна періодика:** Газета виглядає як преміальне цифрове міське медіа — поєднання класичної газетної естетики з яскравим нео-бруталізмом та дружнім гумором.
2. **Модульна система «цеглинок» (Masonry):** Кожен змістовний блок є окремою самодостатньою карткою (`article.card`). Жодних безформних "мега-блоків", у які намішано 5 різних типів контенту.
3. **Строга колірна дисципліна:** Фірмова фіолетово-жовта палітра з глибоким нічним «чорнильним» фоном (`--ink`) для головних подій.
4. **Консистентна типографіка:** Чіткий поділ ролей між акцентним шрифтом `Unbounded` та читабельним текстовим `Onest`. Жодних довільних стилів заголовків.
5. **Передбачувана адаптивність:** Ідеальний вигляд на десктопі (2 колонки) та мобільних пристроях (1 колонка) без стрибків верстки (Zero Cumulative Layout Shift).

---

## 2. Колірна палітра та дизайн-токени

Усі кольори визначаються через CSS-змінні у корені `:root`. Пряме використання hardcoded кольорів (HEX, RGB) у компонентах заборонено.

### Семантичні токени

| Токен | Світла тема (`light`) | Темна тема (`dark`) | Призначення |
| :--- | :--- | :--- | :--- |
| `--bg` | `#e6e4f1` | `#000000` | Фонова підкладка сторінки |
| `--card` | `#ffffff` | `#111111` | Базовий фон стандартних карток |
| `--text` | `#0b0919` | `#ffffff` | Основний контрастний текст (заголовки, акценти) |
| `--text2` | `#26223d` | `#e8e8e8` | Текст другого рівня- Для напівпрозорих елементів поверх `--ink` використовується `rgba(255, 255, 255, 0.08…0.15)`, але для звичайних карток — лише змінні `--pill` та `--line`.

## 3. Типографіка та ієрархія тексту

Шрифтова пара:
- **Display:** `"Unbounded"` (ваги 600, 800) — використовується для шапки газети, великих чисел, головних заголовків `h1` та `h2`.
- **Body:** `"Onest"` (ваги 400, 500, 600, 700) — використовується для статей, підзаголовків, списків, цитат і рубрик.

### Шкала розмірів та ролей

| Селектор / Клас | Шрифт | Розмір / Leading | Вага | Призначення |
| :--- | :--- | :--- | :--- | :--- |
| `h1` | Unbounded | `clamp(32px, 6.4vw, 72px)` / 1.02 | 800 | Назва газети у шапці |
| `.sub` | Onest | `clamp(16px, 2vw, 20px)` / 1.55 | 400 | Слоган / дата під назвою газети |
| `h2` | Unbounded | `clamp(22px, 2.6vw, 30px)` / 1.15 | 600 | Головний заголовок секції (Новина дня, Галерея, Тиждень) |
| `h3` | Onest | `21px` / 1.2, tracking `-0.02em` | 700 | Заголовок стандартної статті або новини |
| `.lede` | Onest | `16px` / 1.45 | 400–500 | Лід (вступний абзац / підзаголовок новини) |
| `.text p` | Onest | `16px` / 1.55 | 400 | Основний абзацний текст статей |
| `.label` | Onest | `14px` / 1 | 600 | Назва рубрики з круглим маркером 9px |
| `.big` | Unbounded | `64px` / 1, tracking `-0.05em` | 800 | Головна метрика / статистика |
| `.pill` | Onest | `12.5px` | 400–500 | Міні-тег, метадані, дата в історії |
| `.chip` | Onest | `13.5px` | 500–600 | Чіпс у шапці секції (`.gh`) |
| `.line` | Onest | `15px` / 1.4 | 400 | Елемент списку (короткі новини, топ авторів) |
| `.line b` | Onest | `12.5px` | 600 | Підпис автора або місце в топі |

> [!IMPORTANT]
> **Антипатерн:** Створювати спеціальні локальні класи на кшталт `.wh-title`, `.wh-sub`, `.wsub-title` заборонено! Усі заголовки статей повинні використовувати `h3` або `.label`, а підзаголовки — `.lede`.

## 4. Сетка, отступы и радиусы

- **Ширина контейнера (`.wrap`):** `max-width: 1080px; margin: 0 auto; padding: 20px 20px 48px;`.
- **Сітка (`.masonry`):** Нативний **CSS Multi-column** (`column-count: 2; column-gap: 16px;`) без абсолютного позиціонування та JS-скриптів розрахунку координат:
  - **Картки 1 колонки (`.card`):** `break-inside: avoid; margin: 0 0 16px 0; width: 100%; display: block;`. Захищені від розриву всередині стовпця.
  - **Фіксація правої колонки (`.card.weather`):** Має `break-before: column;`. Це офіційний W3C CSS стандарт фрагментації, який надійно розпочинає другу колонку з блоку Погоди, гарантуючи розташування Wordle та Погоди поруч у верхньому ярусі незалежно від обсягу та висоти новин під ними.
  - **Повнорозмірні картки (`[data-span="2"]`):** `column-span: all; width: 100%; margin: 0 0 16px 0;` (Новина дня, Спецвипуск тижня, Кросворд, Квіз, Галерея, Анекдоти). Розтягуються на всю ширину сторінки, автоматично перериваючи multi-column flow.
  - **Чергування статей у шаблоні:** Непарні статті (`loop.index0 % 2 == 0`) направляються у ліву колонку під Wordle та Цитати, а парні статті (`loop.index0 % 2 == 1`) — у праву колонку під Погоду та Героя дня, забезпечуючи ідеальний вертикальний баланс сторінки.
  - **Мобільний вигляд (`<= 660px`):** `column-count: 1 !important;`, на `.card.weather` задається `break-before: auto !important;`. Картки природно вишиковуються в одну колонку без горизонтального скролу чи стрибків.
- **Радіуси скруглення (Border Radius):**
  - Картка (`.card`): `22px`
  - Медіа-контейнер (`.mf`, `.nmedia`): `14px` – `16px`
  - Рядки списків (`.line`): `14px`
  - Цитати (`.quotes .line`): `18px 18px 18px 4px` (форма хмаринки діалогу)
  - Чіпси, пігулки, кнопки (`.chip`, `.pill`, `.btn`, `.wgeo`): `999px`

## 5. Архетипи карток

Кожна картка газети належить до одного з 5 уніфікованих архетипів:

### Архетип 1: Головна новина / Фокусний блок (`.news`, `.week`)
- **Ширина:** `data-span="2"`
- **Фон:** `--ink`
- **Кольори:** Заголовок `#ffffff`, рубрика та маркер `--hi`, лід `--ink-soft`, текст `#f1effc`.
- **Структура:** Двоколонковий або збалансований лейаут із медіа зліва/справа.

### Архетип 2: Акцентна картка (`.hero`, `.joke`)
- **Фон:** Соковитий жовтий `--hi`, рамка `--hi`.
- **Текст:** `--hi-text` (`#0b0919`).
- **Сенс:** Миттєве привернення уваги читача до героя номера або панчлайну. Завдяки природному балансу висот Wordle та погоди природно займає місце під блоком погоди.

### Архетип 3: Стандартна редакційна картка (`.card`)
- **Ширина:** 1 колонка.
- **Фон:** `--card`, межа `1px solid var(--line)`.
- **Структура:**
  1. Медіа (якщо є) через макрос `{{ show(media_id, title) }}`
  2. Рубрика `<span class="label">Назва</span>`
  3. Заголовок `<h3>...</h3>`
  4. Текст `<div class="text"><p>...</p></div>`

### Архетип 4: Інфографіка та статистика (`Циفري дня`, `week-stats`)
- **Єдиний стандарт діаграм активності (`.hours`, `.wbars`):**
  - **Без зайвих рамок основи:** Стовпчики починаються від фону без штучних ліній `border-bottom`.
  - **Верхівки стовпчиків:** Уніфіковане заокруглення `border-radius: 4px 4px 0 0` (або `5px 5px 0 0`).
  - **Колірна ієрархія:**
    - Порожні/нульові значення: фоновий нейтральний `var(--pill)`.
    - Звичайні дні/години з активністю (`.on`): `background: var(--accent); opacity: 0.5;`.
    - Пікові значення (`.peak`): `background: var(--accent); opacity: 1; box-shadow: 0 0 10px rgba(139, 92, 246, .35);`.
  - **Мікро-анімація:** Плавний hover без зміни висоти чи геометричних зсувів (`filter: brightness(1.25); opacity: 1; transition: opacity .15s ease, filter .15s ease;`). Заборонено `transform: scaleY`, що викликає тремтіння стовпчиків під курсором.
  - **Підписи осей:** `font-size: 11.5px`, `font-weight: 600`, `color: var(--muted)`.

### Архетип 5: Інтерактив та ігри (Wordle, Квіз «Угадай цитату», Кросворд)
- **Модульна архітектура екранів:**
  1. **Стартовий оверлей (Start Screen):** Дружній екран знайомства з грою (`.wstart` усередині `.wov`/`.qov`) — іконка або демо-цитата, правила, кнопка «Грати» з плавним переходом `wfade`.
  2. **Ізоляція підкладки:** Під час показу оверлею (`start` або `result`) ігрове тіло (`.wbody`, `.qbody`) має `visibility: hidden`, а сцена (`.wstage`, `.qstage`) — `overflow: hidden; border-radius: 16px;`. Це виключає просвічування кнопок або клавіатури по кутках.
  3. **Стабільна геометрія (Zero CLS):** Сцена має фіксовану мінімальну висоту (`.wstage` — 480px, `.qstage` — 420px), а всі допоміжні кнопки розміщуються в єдиному нижньому барі дій, зберігаючи незмінну висоту картки на всіх етапах.
  4. **Оверлей результату (Result Screen):** Рахунок `.score`, оцінка гри, синхронізовані індикатори спроб (`.qpat span.c` #2fa36b та `.qpat span.w` #e0324b), кнопки «Скопіювати результат», «Пройти ще раз» та кнопка закриття `×`.
  5. **Кнопка повернення:** Кнопка «Подивитись результат» розміщується в центральному барі дій завершеної гри без зміни габаритів картки.

### Архетип 6: Сервісні віджети (`Погода`)
- **Мінімалістична шапка:** Тільки семантичний заголовок `<span class="label">Погода</span>` без зайвих кнопок ручного запиту геолокації (визначення відбувається автоматично через GPS/IP).
- **Pixel-perfect Skeleton:** Розмітка стану завантаження (`#wx`) повинна 1-в-1 повторювати геометрію готової погоди (3 картки днів `.wd`, пігулки `.sk-pill` висотою 25px, блок поточної температури) для нульового Layout Shift.

## 6. Медіа та стікери

- **Фото та GIF:** Завжди транслюються через макрос `show(mid, caption)`.
  - Обгортка `.mf` має `aspect-ratio: 4 / 3`, `border-radius: 14px`, `overflow: hidden`, `background: var(--pill)`.
  - Зображення мають `object-fit: cover` та плавний ховер-зум `transform: scale(1.06)`.
  - Лайтбокс активується через атрибут `data-lightbox`.
- **Стікери (`.stk`):**
  - Фіксована ширина `150px` з прозорим фоном.
  - Hover-ефект: `transform: scale(1.12)`.
  - Lottie стікери рендеряться з фолбеком на емодзі.
- **Заборона подвійного огортання:** Ніколи не вкладати `show(...)` у додатковий контейнер з власними класами зображень (це призводить до ламання `aspect-ratio` та подвійних відступів).

## 7. Специфікація тижневого випуску (Усунення «Messy»)

Тижневий випуск раніше мав проблему надлишкового нашарування: все поміщалося в один гігантський блок з довільними стилями, напівпрозорими підкладками та невдалими відступами.

### Нова модульна структура тижня:

```
┌─────────────────────────────────────────────────────────────┐
│  КАРТКА 1: Головне за тиждень (.card.week [data-span="2"])  │
│  - Шапка (.gh): Заголовок тижня + чіпси з діапазоном        │
│  - Лід (.lede)                                              │
│  - Сітка (.wk):                                             │
│    ┌─────────────────────────┬───────────────────────────┐  │
│    │  Топ-історії (.stories) │  Герой тижня (.whero)     │  │
│    │  (1, 2, 3... з датами)  │  (жовта плашка в стилі    │  │
│    │                         │   карти Героя дня)        │  │
│    └─────────────────────────┴───────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  КАРТКА 2: Хроніка тижня (.card.week-chronicle [span="2"])  │
│  - Шапка (.gh): "Хроніка тижня" + кількість випусків        │
│  - Сітка (.wh-grid) на 2–3 колонки зі стандартними картками │
│    кожного дня (.wh-card) на фоні var(--pill):              │
│    - Рубрика: День тижня · Дата                             │
│    - Медіа дня (чистий show)                                │
│    - Заголовок дня (h3)                                     │
│    - Підзаголовок (.lede) та опис (.text)                   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  КАРТКА 3: Цифри тижня (.card.week-stats [data-span="2"])   │
│  - Шапка (.gh): "Цифри тижня" + чіпси                       │
│  - Сітка 4 ключових метрик (.wstat-grid)                    │
│  - Тіло (.wstat-body):                                      │
│    ┌─────────────────────────┬───────────────────────────┐  │
│    │ Графік 7 днів (.wbars)  │ Топ балакунів (.line)     │  │
│    └─────────────────────────┴───────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### Виправлення специфічних помилок тижневого блоку:
1. **Герой тижня (`.whero`):** Оформлюється аналогічно до картки `.hero` щоденного випуску: жовтий фон `--hi`, контрастний темний текст `--hi-text`, заголовок імʼя та регалії.
2. **Хроніка новин кожного дня (`.wh-card`):** Замість темного скляного ефекту з довільними білими прозоростями картки використовують системний `--pill` або `--card` з лінією `--line`. Вони органічно виглядають і в світлій, і в темній темах.
3. **Діаграма тижня (`.wbars`):** Очищена від застарілих дублікатів класів (`.wbars-light` видалено). Використовує ті самі стилі піків `--accent` та скруглень, що й добовий графік `.hours`.
4. **Усунення мертвого коду:** Видалено непотрібні стилі `.wsub`, дублюючі медіа-обгортки та несемантичні `h4`.

## 8. Чеклист перевірки перед випуском номера

- [ ] Всі кольори використовують системні змінні (`--bg`, `--card`, `--accent`, тощо).
- [ ] Жоден текст на жовтому фоні не є світлим/білим.
- [ ] Заголовки карток мають клас `h3` або `h2` і не використовують ad-hoc розміри.
- [ ] Усі рубрики оформлені через `.label` і мають кольорову круглу крапку-індикатор.
- [ ] Медіа виводиться через макроси `show` або `pic`, без зайвих зовнішніх обгорток.
- [ ] На мобільному екрані (375px–430px) відсутній горизонтальний скрол (`overflow-x`), колонки плавно вишикувані в одну лінію.
- [ ] Обидві теми (Light / Dark) читабельні та контрастні.
